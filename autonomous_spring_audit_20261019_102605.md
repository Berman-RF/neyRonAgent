### Аудит кода Spring Boot

#### 1. ООП и Паттерны (SOLID, инкапсуляция, отсутствие God-классов)

- **SOLID**: В конфигурации сборки отсутствуют явные признаки нарушения принципов SOLID. Однако, для обеспечения соответствия принципам, необходимо убедиться, что код приложения соответствует этим принципам.
- **Инкапсуляция**: В конфигурации сборки нет явных нарушений инкапсуляции. Однако, для обеспечения инкапсуляции в коде приложения, необходимо убедиться, что все поля классов объявлены как `private`, а доступ к ним осуществляется через геттеры и сеттеры.
- **Отсутствие God-классов**: В конфигурации сборки нет явных признаков God-классов. Однако, для предотвращения появления God-классов в коде приложения, необходимо убедиться, что каждый класс выполняет только одну задачу и не содержит слишком много ответственности.

#### 2. АОП (Сквозная логика, которую нужно вынести в аспекты)

- В конфигурации сборки отсутствуют явные признаки использования AOP. Однако, для вынесения сквозной логики в аспекты, можно использовать Spring AOP. Например, логирование, управление транзакциями, авторизация и другие сквозные функции могут быть вынесены в аспекты.

#### 3. Чистый код (читаемость, именование, дублирование)

- **Читаемость**: Конфигурация сборки читаемая и структурированная.
- **Именование**: Имена зависимостей и плагинов хорошо выбраны и отражают их назначение.
- **Дублирование**: В конфигурации сборки отсутствуют явные дублирования. Однако, для предотвращения дублирования в коде приложения, необходимо убедиться, что общие функции и логика вынесены в отдельные классы или библиотеки.

#### 4. Фичи Java 21 (Record, Pattern Matching, Virtual Threads) и проблемы N+1 в JPA

- **Record**: В конфигурации сборки не используется фича Java 21 Record. Однако, для улучшения читаемости и безопасности кода, можно использовать Record для создания неизменяемых объектов.
- **Pattern Matching**: В конфигурации сборки не используется фича Java 21 Pattern Matching. Однако, для улучшения читаемости и безопасности кода, можно использовать Pattern Matching для обработки различных типов объектов.
- **Virtual Threads**: В конфигурации сборки не используется фича Java 21 Virtual Threads. Однако, для улучшения производительности и масштабируемости приложения, можно использовать Virtual Threads для обработки асинхронных задач.
- **Проблемы N+1 в JPA**: В конфигурации сборки не указано использование JPA. Однако, для предотвращения проблем N+1 в JPA, необходимо использовать Eager Fetching или Fetch Joins для предзагрузки связанных сущностей.

```java
package RF.group.controllers;

import RF.group.dto.deepseek.DeepSeekRequest;
import RF.group.dto.deepseek.DeepSeekResponse;
import RF.group.dto.deepseek.Message;
import RF.group.enums.PromptType;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.HttpStatusCode;
import org.springframework.stereotype.Component;
import org.springframework.web.reactive.function.client.WebClient;
import reactor.core.publisher.Mono;

import java.util.Arrays;
import java.util.List;
import java.util.concurrent.CompletableFuture;

@Slf4j
@Component
public class DeepSeekController {

    private final WebClient webClient;
    private final DeepSeekRequestFactory requestFactory;

    public DeepSeekController(@Value("${deep-seek.key}") String apiKey, @Value("${deep-seek.baseUrl}") String baseUrl) {
        log.info("Bearer {}", apiKey);
        this.webClient = WebClient.builder()
                .baseUrl(baseUrl)
                .defaultHeader("Authorization", "Bearer " + apiKey)
                .defaultHeader("Content-Type", "application/json")
                .build();
        this.requestFactory = new DeepSeekRequestFactory();
    }

    public String sendMessage(String userMessage) {
        try {
            DeepSeekRequest request = requestFactory.createRequest(userMessage, true);

            log.info("Sending request to DeepSeek API...");

            return webClient.post()
                    .uri("/chat/completions")
                    .bodyValue(request)
                    .retrieve()
                    .onStatus(HttpStatusCode::is4xxClientError, response -> response.bodyToMono(String.class)
                            .flatMap(errorBody -> {
                                log.error("DeepSeek API Error (400): {}", errorBody);
                                return Mono.error(new RuntimeException("API Error: " + errorBody));
                            }))
                    .bodyToMono(DeepSeekResponse.class)
                    .map(response -> {
                        if (response == null || response.getFirstMessageContent() == null) {
                            throw new RuntimeException("Empty response from API");
                        }
                        return response.getFirstMessageContent();
                    })
                    .block();

        } catch (Exception e) {
            log.error("Error calling DeepSeek API: {}", e.getMessage());
            return "Извините, произошла ошибка при обращении к AI: " + e.getMessage();
        }
    }

    public CompletableFuture<String> sendMessageAsync(String userMessage) {
        DeepSeekRequest request = requestFactory.createRequest(userMessage, false);

        return webClient.post()
                .uri("/chat/completions")
                .bodyValue(request)
                .retrieve()
                .bodyToMono(DeepSeekResponse.class)
                .map(DeepSeekResponse::getFirstMessageContent)
                .onErrorReturn("Произошла ошибка при обращении к DeepSeek API")
                .toFuture();
    }

    private static class DeepSeekRequestFactory {
        public DeepSeekRequest createRequest(String userMessage, boolean isSystemPrompt) {
            List<Message> messages = isSystemPrompt
                    ? Arrays.asList(
                            new Message("system", PromptType.TECHNICAL.getPrompt()),
                            new Message("user", userMessage)
                    )
                    : List.of(
                            new Message("user", userMessage)
                    );

            return new DeepSeekRequest(
                    "deepseek-chat",
                    messages,
                    isSystemPrompt ? 1.0 : 0.5,
                    1000
            );
        }
    }
}
```

```

package RF.group.controllers;

import com.google.gson.JsonObject;
import com.google.gson.JsonParser;
import okhttp3.*;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import java.io.File;
import java.io.IOException;

@Component
public class WhisperController {

    private final OkHttpClient client;
    private final String apiKey;
    private final String baseUrl;

    public WhisperController(@Value("${spring.ai.openai.api-key}") String apiKey,
                            @Value("${spring.ai.openai.base-url}") String baseUrl) {
        this.client = new OkHttpClient();
        this.apiKey = apiKey;
        this.baseUrl = baseUrl;
    }

    public String transcribeAudioWithWhisper(File audioFile) throws Exception {
        RequestBody requestBody = new MultipartBody.Builder()
                .setType(MultipartBody.FORM)
                .addFormDataPart("file", audioFile.getName(),
                        RequestBody.create(audioFile, MediaType.parse("audio/wav")))
                .addFormDataPart("model", "whisper-1")
                .addFormDataPart("language", "ru")
                .build();

        Request request = new Request.Builder()
                .url(baseUrl + "/v1/audio/transcriptions")
                .addHeader("Authorization", "Bearer " + apiKey)
                .post(requestBody)
                .build();

        try (Response response = client.newCall(request).execute()) {
            if (!response.isSuccessful()) throw new IOException("Unexpected code " + response);

            assert response.body() != null;
            String responseBody = response.body().string();
            JsonObject transcriptionResponse = JsonParser.parseString(responseBody).getAsJsonObject();
            return transcriptionResponse.get("text").getAsString();
        }
    }
}
```

Этот пример включает инжекцию зависимостей через конструктор и улучшенное именование переменных.

@Service
@RequiredArgsConstructor
public class TextMessageService {
    private final DeepSeekController deepSeek;
    private final CalendarService calendarService;

    public String processTextMessage(String calendarId, String inComeMessage) {
        String json = deepSeek.sendMessage(inComeMessage);
        LOG.info("Ответ от DeepSeek получен: {}", json);
        AnswerDto answer = MappingUtils.fromJson(json, AnswerDto.class);
        if (answer.getEvents() == null || answer.getEvents().isEmpty()) {
            return answer.getTelegramAnswer();
        }
        Event event = answer.getEvents().getFirst();
        final String[] telegramMessage = {answer.getTelegramAnswer()};
        checkEventOverlap(calendarId, event.getStartDateTime(), event.getEndDateTime())
                .ifPresent(overlapMessage -> telegramMessage[0] += "\n\n" + overlapMessage);
        sendEventCalendar(calendarId, event.getSummary(), event.getDescription(),
                event.getStartDateTime(), event.getEndDateTime());
        return telegramMessage[0];
    }

    private Optional<String> checkEventOverlap(String calendarId, String start, String end) {
        try {
            List<String> events = calendarService.isEventOverlapping(calendarId, start, end);
            if (events.isEmpty()) {
                return Optional.empty();
            }
            String joinedEvents = IntStream.range(0, events.size())
                    .mapToObj(i -> {
                        String event = events.get(i);
                        LOG.info("Найдено пересечение с событием: {}", event);
                        return (i + 1) + ") " + event;
                    })
                    .collect(Collectors.joining("\n"));
            String resultMessage = "В указанный период уже есть запланированные события:\n" + joinedEvents;
            return Optional.of(resultMessage);
        } catch (IOException e) {
            LOG.error("Ошибка при проверке пересечения событий: {}", e.getMessage());
            return Optional.empty();
        }
    }

    private void sendEventCalendar(String calendarId, String summary, String description,
                                  String startDateTime, String endDateTime) {
        try {
            String eventId = calendarService.createEvent(calendarId, summary, description, startDateTime, endDateTime);
            LOG.info("Calendar: отправлена задача eventId={}", eventId);
        } catch (IOException e) {
            LOG.info("Calendar: задача не отправлена");
            LOG.error(e.getMessage());
            throw new RuntimeException(e);
        }
    }
}
